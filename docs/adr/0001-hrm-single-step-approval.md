# HRM 单据审批采用单步通用审批，不引入工作流引擎

演示站（ruoyioffice.com）的 HRM 单据依赖平台级 BPM 流程中心审批；本项目没有工作流模块。我们决定为全部 HRM 单据实现一套共享的通用审批机制：统一单据状态机（未提交/审批中/审批通过/审批不通过/已撤销）+ 一张共享审批记录表（记录动作/审批人/时间/意见）+ 单步审批（审批权由按钮码经 casbin 控制，"谁有审批按钮权限谁能审"）。

## Considered Options

- 对接真正的多级工作流（流程定义/节点/回调）：本项目无 BPM，从零建工作流引擎复杂度失控，拒绝。
- 每类单据各自实现审批：15+ 类单据高度同构，重复代码，拒绝。

## Consequences

- 审批通过后的业务回写（入职建档、转正、调动、离职、假期余额扣减、薪资确认等）在单据自己的 service 中实现，不走回调路由。
- 未来若引入工作流模块，可替换审批层而保留单据业务逻辑，因此状态机与回写逻辑必须与审批机制解耦。
