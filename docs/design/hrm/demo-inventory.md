# HRM 功能规格：ruoyioffice.com 演示站走查清单

> 来源：https://ruoyioffice.com/web/#/hrm/... 演示站逐页走查（2026-11-15）。
> 本文档是「以演示站为规格全新设计」的功能清单基准；字段名为演示站表格列/筛选器/按钮的中文名。
> 前端路由段按域划分：`org` / `employee` / `employee-relation` / `attendance` / `recruitment` / `training` / `reward` / `salary` / `performance`。

## 0. 全局约定（从演示站观察到）

- **单据编号**：`HR{类型码}-{YYYYMMDD}{5位流水}`，如 `HR201-2026111200001`。已观察类型码：
  - 201 员工入职、202 员工转正、203 人事调动、204 员工离职（推断）、205 请假销假、206 补卡、207 招聘需求、208 录用审批、209 薪资确认审批、210 发薪登记、211 绩效批次结果审批、215 奖惩单、216 培训计划、217 加班申请。
  - 培训班次编号独立：`PX{yyyyMMddHHmmss}`；绩效批次编号：`PERF-…`；薪资批次编号：`SA{yyyyMMdd}{4位}`。
- **单据状态**：未提交（草稿/暂存）/ 审批中 / 审批通过 / 审批不通过 / 已撤销。
- **列表页通用模式**：筛选区（可展开/收起）+ 工具栏（新增/导出/批量删除）+ 表格 + 行操作（修改/删除）。
- **跨域耦合**（演示站真实存在）：
  - 薪资试算引用：考勤锁定（未锁定则按实时打卡）、奖惩（奖惩奖励/奖惩扣款项目）、加班调休入账、绩效（未接入时按"岗位绩效基准或规则兜底"）、员工须已生成系统用户。
  - 绩效结果：已签收 / 已同步薪酬 状态。
  - 假勤：日结/月报锁定（锁定后考勤月报才能作为计薪依据）。
  - 招聘录用审批 → 计划入职日期/试用期 → 衔接员工入职。
  - 培训班次结业 → 证书发放。

## 1. 组织架构

### 1.1 组织管理 `/hrm/org/orginfo`
- 树表：组织名称（树）、组织类型（公司/部门）、负责人、显示顺序、组织状态（开启/关闭）、创建时间。
- 工具栏：新增组织、收缩、导入、导出、批量删除；行操作：新增下级、编辑、删除。
- 疑似对应开源源码 `system_dept`+`orgType` 的加强版（演示站有负责人、导入导出）。

### 1.2 组织架构图 `/hrm/org/org-chart`
- 可视化组织树：负责人、本级人数、汇总人数；拖拽移动、滚轮缩放、点击节点展开/收起；刷新。

## 2. 人事档案

### 2.1 员工档案 `/hrm/employee/employee-archive-list`
- 筛选：员工工号、姓名、所属部门。
- 工具栏：新增、导出、**导入员工**、**批量生成用户**、批量删除。
- 列：员工工号、姓名、性别、所属部门、职位、职务、人员状态（正式/试用期/实习生…）、入职日期、转正日期、所属单位、手机号、邮箱、**用户状态**（是否已生成系统账号）、创建时间。
- 行操作：修改、**生成用户**、删除。
- （开源源码佐证字段）主表还有：生日、血型、民族、政治面貌、婚姻状况、籍贯、身高体重、身份证、户口地址、现住址、紧急联系人/电话、头像、工资开户行/工资卡账户、备注；从表：教育经历、工作经历、家属。

### 2.2 劳动合同到期预警 `/hrm/employee/employee-contract-expiring`
- 筛选：员工姓名、员工工号、到期范围（日期区间）。
- 列：员工工号、员工姓名、所属部门、合同生效日、合同到期日、距到期(天)、续签次数、合同状态、操作。

### 2.3 待续签合同 `/hrm/employee/employee-contract-renewable`
- 与 2.2 同结构（不同筛选口径），行操作应含续签。

### 2.4 证照到期预警 `/hrm/employee/certificate-expiring`
- 筛选：姓名、工号、证书类型。
- 列：姓名、工号、部门、证书类型（身份证等）、证号（脱敏）、到期日、距到期天数、状态（即将到期）。

## 3. 人事管理（4 类单据）

### 3.1 员工入职 `/hrm/employee-relation/entry-list`
- 筛选：单据编号、单据状态、姓名。
- 列：单据编号(HR201)、单据状态、姓名、手机号、邮箱、员工所属部门、职位、职务、人员状态、入职日期、预计转正日期、申请人、员工所属公司、创建时间。
- 新增表单：Tab「单据信息」；节：基本信息（*必填项、员工照片上传、民族、政治面貌、婚姻状况、文化程度、籍贯、现居住地、户口所在地、紧急联系人/电话、工资开户行、工资卡账户、职位、职务、试用期(月)、所属部门、所属公司、入职日期、预计转正日期、备注）、工作经历（子表可增行）、教育经历（子表）、家庭成员（子表，页面滚动区）、附件信息（上传）；按钮：提交/保存。
- 审批通过后自动建员工档案（开源源码逻辑：工号自动生成、预计转正=入职日期+试用期）。

### 3.2 员工转正 `/hrm/employee-relation/regular-list`
- 筛选：单据编号、单据状态、员工工号。
- 列：单据编号(HR202)、单据状态、员工工号、员工姓名、员工所属部门、员工所属公司、职位、职务、人员状态、入职日期、转正日期、预计转正日期、申请人、创建时间。
- 通过后：人员状态→正式，写转正日期。

### 3.3 人事调动 `/hrm/employee-relation/transfer-list`
- 筛选：单据编号、单据状态、员工工号。
- 列：单据编号(HR203)、单据状态、员工工号、员工姓名、员工所属部门、员工所属公司、异动类型（调岗/调部门/调薪…）、原部门、变更为部门、原公司、变更为公司、生效日期、申请人、创建时间。
- （开源源码佐证）调动原因、是否立即生效；非立即生效由定时任务在生效日处理。

### 3.4 员工离职 `/hrm/employee-relation/resignation-list`
- 列（在调动列基础上）：离职类型、离职原因、离职日期、最后工作日期。
- （开源源码佐证）交接人、薪资结算日期；定时任务在离职日统一置离职状态。

## 4. 假勤管理

### 4.1 我的假勤
- **个人看板** `/hrm/attendance/my/dashboard`：今日卡片（考勤组名、今天休息、上/下班打卡状态、去打卡）、本月统计（应出勤/已出勤/迟到/早退/缺卡/缺勤/加班/加班时长/年假可用）、考勤锁定日提示（"11月考勤将于12-05锁定"）、快捷操作（请假/补卡/加班/销假）、考勤日历（逐日：休息/异常/缺勤+打卡时间）。
- **考勤打卡** `/hrm/attendance/my/attendance-punch`：筛选打卡日期区间、签到/签退状态；列：日期、星期、签到时间、签到状态（正常/外勤）、签到地点（GPS 地址）、签退…、加班（是/否）。

### 4.2 假勤申请（3 类单据）
- **请假销假** `/hrm/attendance/apply/leave-cancel-list`：HR205；筛选单据编号/单据状态/请假类型（事假/年假/调休假…）；列：单据编号、单据状态、请假类型、预计开始/结束时间、预计天数、实际开始/结束时间、实际天数、申请人、部门、创建时间。销假=回填实际时间。
- **补卡管理** `/hrm/attendance/apply/card-replacement-list`：HR206；筛选+补卡类型（上班卡/下班卡）；列：补卡日期、补卡类型、补卡时间、原上班打卡、原下班打卡。
- **加班申请** `/hrm/attendance/apply/overtime-bill-list`：HR217；筛选+当天类型（工作日/休息日/法定节假日）；列：加班日期、当天类型、开始/结束时间、申请时长、**核定时长**、补偿方式（调休…）、来源（员工申请）、申请人、部门。

### 4.3 排班管理
- **排班表** `/hrm/attendance/scheduling/schedule`：考勤组选择器 + 月份选择 + 姓名/工号/部门搜索；按钮：周期生成、按模板、复制周、导入、导出、发布本月；矩阵表：员工 × 当月每日（班次标记）+ 工时。
- **排班周期** `/hrm/attendance/scheduling/schedule-cycle`：筛选周期名称/状态；列：周期名称、班次序列（如「夜 夜 坐 坐 查夜 查夜 标准 标准 休」）、周期天数、适用考勤组、状态（启用）、备注。

### 4.4 假勤数据
- **考勤统计** `/hrm/attendance/data/punch-statistics`：统计卡（统计人数/异常人数/迟到次数/早退次数/缺卡次数/记录条数）；筛选日期区间、用户姓名、仅看异常；列：员工、部门、应出勤天、出勤天、缺勤天、迟到、早退、缺卡、异常合计、异常摘要；行操作：查看明细。
- **打卡记录** `/hrm/attendance/data/punch-record`（管理端）：筛选日期区间/姓名/签到状态；工具栏：新增、导出、**导入外部考勤数据**、**手动日结**、批量删除；列：用户姓名、登录账号、打卡日期、星期、年度周、签到时间/状态/地点、签退…；行操作：修改、删除。
- **假期余额** `/hrm/attendance/data/leave-balance`：筛选姓名/部门（含下级）/假期类型/年度；按钮：**初始化本年度额度**；列：工号、姓名、部门、入职日期、余额（可用/应发）；行操作：年假明细、调整、流水。
- **考勤月报** `/hrm/attendance/data/month-report`：筛选月份/部门（含下级）/考勤组/姓名、只看异常、只看锁定后变更；按钮：锁定记录、重新计算、锁定月报、解锁、导出；列：部门、考勤组、姓名、应出勤、实出勤、迟到、早退、缺卡、旷工、工作日加班(h)、休息日加班(h)、节假日加班(h)、调休入账(h)；行操作：日明细；锁定状态标识。

### 4.5 假勤设置
- **组织默认规则** `/hrm/attendance/setting/attendance-config`：规则优先级说明「考勤组 > 组织默认规则；未加入考勤组的员工按本部门规则执行；本部门没设置则用最近上级组织的规则」；按组织维护默认考勤规则；快速开始、重新体检。
- **考勤组** `/hrm/attendance/setting/group`：筛选名称/班制/状态；列：考勤组名称、班制（**固定班制/排班制/自由工时**）、考勤时间（如 周一至周五 09:00-18:00；排班制注明未排班兜底）、适用范围（部门含下级、指定人员）、生效人数、负责人、状态；按钮：生效规则查询、新增考勤组；行操作：编辑、停用、更多。
- **班次管理** `/hrm/attendance/setting/shift`：列：班次名称、上下班时间（支持跨天 22:00-次日06:00）、休息时段、标准工时、弹性（弹性分钟数/不弹性）、引用考勤组、状态、备注。
- **假期类型** `/hrm/attendance/setting/leave-type`：列：类型名称、类型编码（annual_leave/comp_leave/sick_leave/other_leave…）、类型值、**余额管理**（是/否）、需要附件、默认天数、排序、状态。预置：年假/调休假/事假/病假/婚假/产假/陪产假/丧假/其他。
- **加班规则** `/hrm/attendance/setting/overtime-rule`：列：规则名称、工作日/休息日/法定节假日策略（需审批/免审批、需打卡/免打卡、调休×N）、最小单位（30分钟）、月上限、使用的考勤组、状态。

## 5. 招聘管理

- **招聘需求** `/hrm/recruitment/requirement-list`：HR207；筛选需求编号/状态/岗位名称；列：需求编号、状态、岗位名称、岗位类别（技术类…）、需求人数、紧急度（普通/紧急）、期望到岗日期、所属部门、申请人。
- **招聘职位** `/hrm/recruitment/position-list`：筛选岗位名称/来源需求单/岗位类别；列：岗位名称、来源需求单、岗位类别、招聘负责人、状态（招聘中）、招聘人数、已录用人数、发布日期。
- **候选人中心** `/hrm/recruitment/candidate-list`：筛选姓名/手机号/来源渠道；工具栏：新增、**Excel导入**、**邮箱线索入库**、**文本识别补录**（AI）、批量删除；列：姓名、手机号、邮箱、来源渠道、最高学历、当前公司、当前岗位、期望薪资、状态（新线索/已投递/录用通过…）。
- **录用审批** `/hrm/recruitment/offer-list`：HR208；列：单据编号、状态、候选人、职位、计划入职日期、试用期(月)、职级（初级/中级…）、汇报人、申请人。

## 6. 培训管理

- **培训计划** `/hrm/training/plan`：HR216；列：计划名称、主题、年度、计划类型（专项…）、发布状态（草稿/已发布）、开始/结束日期。
- **培训班次** `/hrm/training/session`：筛选班次名称/培训计划/状态；列：班次名称、讲师、地点、学时、开始/结束时间、状态（已结束…）、班次编号(PX…)；行操作：编辑、**签到**、删除。
- **外出培训申请** `/hrm/training/outbound`：列：员工、培训名称、主办方、开始/结束时间、学时、申请人、部门。
- **培训签到** `/hrm/training/signin`：选择已发布班次；统计应到/已签/未到；**课堂动态码**（动态二维码）；管理员补签（未到名单+确认补签）；签到明细（姓名/工号/部门/签到时间/方式/操作人/原因）；刷新二维码、导出签到明细。
- **证书发放** `/hrm/training/cert-issue`：按钮：**批量发证**、导入外部证书；列：学员、证书名称、证书号（前缀-年-流水，如 JN-2026-000001）、状态（待发/已发/已撤销）、来源（班次结业）、班次、证书文件（预览/下载/撤销）。
- **证书模板** `/hrm/training/cert-template`：列：模板名称、证书类型（合格证/继续教育/荣誉/安全培训证/结业证/技能证明/上岗证/企业…）、来源（系统/企业）、启用/停用、编号前缀（HF/CE/YX/XF/RZ/JN/SG/AQ/HG/JX）；行操作：套用、设计、删除。
- **我的培训** `/hrm/training/my`：我的班次（班次/地点/开始时间/状态）+ 我的培训证书（证书名称/证书号/发证时间/扫描件预览下载）。

## 7. 奖惩管理

- **奖惩单** `/hrm/reward/bill`：HR215；筛选单据编号/单据状态/奖惩类型；列：单据编号、单据状态、员工、类型（奖励/处分）、级别（公司级/部门级/通报…）、文号、发生日期、金额、申请人、部门。

## 8. 薪酬管理

### 8.1 薪酬设置
- **薪酬主体** `/hrm/salary/setting/subject`：列：主体名称、关联公司、发薪账户、发薪银行、状态。
- **薪酬方案** `/hrm/salary/setting/plan`：列：方案名称、薪酬主体、适用人员状态（正式…）、结算周期（月度）、发薪日、币种、**配置完整度**（项目✓ 计薪✓ 岗位✓ 社保✓ 个税✓ 考勤✓）、状态；行操作：配置。
- **薪资项目** `/hrm/salary/setting/item`：列：项目名称、项目编码（BASIC_SALARY/POST_SALARY/TAX/NET_SALARY/LABOR_COST…）、**项目类型**（固定项/取数项/公式项）、**项目分类**（应发/应扣/成本）、**取值方式**（手工维护/系统取数/公式计算）、计算顺序、显示顺序、状态。预置项目：基本工资、岗位工资、绩效工资、固定补贴、高温补贴、奖惩奖励、缺勤扣款、社保个人、公积金个人、个税、奖惩扣款、其他应扣、实发工资、公司社保、公司公积金、人工成本。

### 8.2 员工薪资档案 `/hrm/salary/archive-list`
- 列：员工姓名、员工ID、所属公司、所属部门、薪酬主体、薪酬方案、状态、固定薪资、固定补贴、生效日期、失效日期。

### 8.3 个税管理
- **专项附加扣除** `/hrm/salary/tax/special-deduction`：按钮：年度维护、导入；列：姓名、身份证、扣除年度、已维护月数、月合计、来源（手工维护）；行操作：维护、删除。（扣除项：子女教育/继续教育/大病医疗/住房贷款利息/住房租金/赡养老人/3岁以下婴幼儿照护）
- **个税累计期初** `/hrm/salary/tax/tax-opening`：列：员工、身份证、主体、年度、截至月、累计收入、累计专项扣除、累计专项附加、累计免税、累计其他扣除、累计应纳税所得额、累计已缴税额；支持导入。
- **员工个税档案** `/hrm/salary/tax/tax-profile`：列：员工、身份证、居民类型（居民个人/非居民个人）、税城市、默认专项附加、状态。

### 8.4 发薪流程
- **薪资批次** `/hrm/salary/batch`：SA 编号；列：批次编号、批次名称、薪酬主体、年份、月份、批次类型（月度批次）、人数、应发合计、应扣合计、实发合计、**试算/确认/发薪/工资条**（四个进度标记 是/否）、试算时间；行操作：查看结果、**试算**、确认审批、发薪登记、工资条、编辑、删除。
- **薪资确认审批** `/hrm/salary/confirm-list`：HR209；关联批次；列：批次编号/名称、薪酬主体、年月、人数、实发合计、创建人。
- **发薪登记** `/hrm/salary/payment-list`：HR210；列：批次编号/名称、薪酬主体、发薪金额、发薪方式（银行代发…）、回执编号、到账时间。
- **工资条管理** `/hrm/salary/payslip`：列：工资条标题、工号、员工姓名、年月、应发、应扣、实发、已发布、已读、已读时间。
- **薪资统计** `/hrm/salary/statistics`：统计卡（员工数/应发合计/应扣合计/实发合计/人工成本）；筛选批次/姓名/部门/异常；薪资台账列：批次、员工、公司、部门、应发、应扣、实发、人工成本、异常、提示/异常（多条告警文本）、已发薪、已发条。

## 9. 绩效管理

### 9.1 设置
- **绩效方案** `/hrm/performance/scheme`：列：方案名称、关联模板、周期类型（月度/季度…）、评估模式（KPI / KPI+行为混合）、评分模式（百分制/等级制/金额制）、**联薪方式**（系数制/金额制）、状态。
- **指标库** `/hrm/performance/setting/indicator`：列：指标编码、指标名称、指标类型（结果指标(KPI)/行为能力）、计量单位、评分规则（公式评分/手工评分）、数据来源（系统取数/手工填报）、默认权重、状态。
- **模板管理** `/hrm/performance/setting/template`：模板名称、状态；模板内配置指标与权重（进入编辑配置）。

### 9.2 批次与任务流
- **考核批次工作台** `/hrm/performance/period-list`：PERF 编号；列：批次编码、批次名称、批次类型（月度/季度）、绩效方案、适用范围（公司/部门/职位/职务/人员状态）、周期开始/结束、结果发布日期、参与人数、状态（**草稿/进行中/待确认/待校准/结果已发布/已发布**）；行操作：进入工作台、编辑、发布、更多。
- **考核任务工作台** `/hrm/performance/assessment-task/workbench`：全周期待办汇总卡：目标确认（被考核人）、自评填报（被考核人）、上级评审（考核人）、校准填报（校准人）、结果确认（被考核人，可发起申诉）、申诉；最近待办列表（类型/批次/员工/当前节点/当前处理人/操作）。
- **目标确认** `/hrm/performance/assessment-task/plan-list`：按批次+员工；列含考核模板、最终得分、最终等级、绩效系数、确认时间、上级评价时间；行操作：确认目标、查看考核任务。
- **自评填报 / 评审填报 / 结果确认** `self-review-list` / `leader-review-list` / `result-confirm-task-list`：考核单号列表（当前节点/任务状态/当前得分/当前等级）。

### 9.3 结果
- **绩效结果** `/hrm/performance/result-list`：列：批次、员工、公司、部门、得分、等级、系数、绩效金额、奖金金额、结果状态、已发布、已签收、**已同步薪酬**、签收时间。
- **绩效批次结果审批** `/hrm/performance/result-confirm-list`：HR211；列：绩效批次、公司、部门、人数、平均得分、绩效金额合计。
- **绩效驾驶舱** `/hrm/performance/statistics`：筛选公司/部门/批次/低分阈值；指标卡（进行中批次/考核完成率/逾期待办/风险人数/平均得分/申诉中）；风险预警 Tab（逾期未办/未填报/连续低分/申诉积压）+ 明细表。
